Candidate Benchmark Shift p-value Noise Floor Gap before run Resolution & Artifacts
Method: Non-parametric Mann-Whitney U test per benchmark per adjacent commit pair on independent per-run medians. Effect size estimated via Hodges-Lehmann difference estimator. Flagged only if statistically significant (p < α) and the shift exceeds 3× the benchmark's own measured noise floor (CV), followed by Benjamini-Hochberg / Benjamini-Yekutieli False Discovery Rate correction across the batch (α=0.05).
Limits: Sequential runs spanning a session break (>15 min) are confounded by host drift; LTO binary-layout reordering can shift hot loops without instruction changes. Re-measure candidates with interleaved A/B + instruction ablation before filing upstream.
